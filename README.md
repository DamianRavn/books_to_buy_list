# books_to_buy_list
A little practise project to help me with learning Vue, Entity Framework and Postgresql.
It's a Todo list, but instead of tasks it's books to be bought.

# Instructions
If you have Nix and Devenv installed, use it with 'devenv up' to start the postgres server, and use 'devenv shell' to get access to dotnet and pnmp.
Otherwise you need to install Postgres, Dotnet, and a package manager yourself.
Navigate to the BookSite.Web folder and 'dotnet build && dotnet run' to start the Rest Api. Navigate to the BookSite folder and run 'pnpm dev' to start the vue website on a localhost.
